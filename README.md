# Academic Paper Hub

模拟各个学术领域的学术论文目录与内容的纯静态网站。文本为主,图片位置预留占位。

## 项目目标

- 覆盖多个主流学术领域(计算机科学、物理学、生命科学、社会科学、人文学科等)
- 每个领域下提供论文目录(列表)与论文详情(摘要、章节、参考文献)
- 纯文字渲染,图片位置以占位区块呈现,后续可替换为真实图片
- 零依赖、可直接用浏览器打开,亦可由静态服务器托管

## 技术选型

- 纯 HTML + CSS + 原生 JavaScript(无构建工具、无框架)
- 数据以 JSON 文件组织,前端动态渲染
- 响应式布局,适配桌面与移动端

## 目录结构

```
.

```

## 版本规划

### v0.1 — 项目骨架
- 初始化目录结构与基础文件
- 完成首页布局(站点标题、领域导航、简介)
- 引入全局样式与基础排版

### v0.2 — 领域分类与目录
- 定义学术领域分类数据(计算机科学、物理、生命科学、社会科学、人文学科等)
- 实现领域目录页:展示各领域及其子方向
- 领域卡片以文字描述为主,封面位置以占位区块代替

### v0.3 — 论文列表与详情
- 每个领域下生成论文列表(标题、作者、年份、摘要片段)
- 论文详情页:摘要、关键词、章节目录、正文段落、参考文献
- 正文内图片位置以 `[图片占位: 说明文字]` 区块呈现

### v0.4 — 占位图片系统
- 统一图片占位组件:固定尺寸、灰色底、居中说明文字
- 在列表卡片、论文正文、领域封面三处接入占位组件
- 预留 `data-image` 属性,便于后续替换为真实图片地址

### v0.5 — 搜索与筛选
- 顶部搜索框:按标题/作者/关键词检索
- 领域与年份筛选器
- 搜索结果高亮关键词

### v0.6 — 内容扩充
- 每个领域补充至少 5 篇模拟论文
- 增加更多子方向(如计算机科学下:机器学习、系统、安全、人机交互)
- 完善参考文献与交叉引用

### v1.0 — 正式版
- 响应式布局优化(移动端汉堡菜单)
- 阅读进度条、回到顶部、暗色模式
- 完整数据校验与可访问性优化
- 发布说明与使用文档

## 后续可选方向(v1.x+)

- 引入轻量构建工具(如 Vite)进行模块化
- 接入真实学术 API(如 arXiv、Crossref)获取论文元数据
- 支持论文 PDF 预览与下载
- 用户收藏、笔记功能(基于 localStorage)

## 本地运行

直接用浏览器打开 `index.html` 即可,或使用任意静态服务器:

```bash
python3 -m http.server 8000
# 访问 http://localhost:8000
```
